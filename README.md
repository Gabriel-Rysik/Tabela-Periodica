# Projeto Tabela Periódica

Este é um programa em Python para consulta de elementos da tabela periódica, integrado a um banco de dados.

## Funcionalidades
* Busca e consulta de elementos químicos
* Interface de menu interativa pelo terminal
* Integração com banco de dados
* Sistema de busca que ignora acentos

## Como executar o projeto

1. Baixe ou clone este repositório no seu computador:
   ```bash
   git clone https://github.com
   ```

2. Entre na pasta do projeto:
   ```bash
   cd projeto_tabela_periodica
   ```

3. Execute o arquivo principal:
   ```bash
   python main.py
   ```

## Arquivos do projeto
* `main.py`: Arquivo principal que inicia o programa.
* `menu.py`: Controle dos menus e interações no terminal.
* `banco_de_dados.py`: Código responsável pela conexão e busca de dados.
* `remover_acentos.py`: Script para padronizar o texto das buscas.
